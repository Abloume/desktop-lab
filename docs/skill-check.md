## 学习约定：题目 ⇄ 练习绑定

每个主题在 `electron-lab/lessons/<n>-<主题>/` 下沉淀三件套：
1. **可运行 demo**（src/ + 根目录 `npm run lesson:0X` 启动）
2. **notes.md**（一句话结论 / 为什么 / 怎么做 / 坑在哪 / 自查题与参考表述 / 对应 demo 位置）
3. **一个 commit**

要求：自查题与参考表述必须能在 demo 里找到对应代码位置，杜绝「笔记是笔记、代码是代码」。

## 打分后

1. 把自评分填入上表并提交（建议单独 commit：`docs: 能力自测`）
2. 自评 ≤ 2 的主题进入阶段 1 重建队列，按依赖顺序排列：
   - 进程模型 → 生命周期 → IPC → preload 与安全 → 窗口 → 打包 → 性能
3. 每个主题的学习产物固定三件套：最小 demo + 一页笔记（一句话结论/展开要点/常见追问/我的表述）+ 一个提交

## 参考表述结构（每个主题都按这个组织）

1. **一句话结论**（30 秒能讲完）
2. **为什么**（设计动机/历史背景）
3. **怎么做**（关键 API 与正确姿势）
4. **坑在哪**（常见错误与自查易错点）
