Lesson 05 · 性能优化与 Web 差异

① 内存构成实测（Q8）

点击刷新：看主进程 / 渲染进程 / GPU 进程各自占多少

内存高的根因：每个窗口一个完整 Chromium 渲染进程 + Node 主进程 + GPU 进程，多窗口线性叠加。

② file:// 能力实测（Q9）

逐个实验，看 file:// 下哪些能用、哪些被拦

结论预告：fetch(file://) ❌ 被拒 · import module ❌ CORS 拦截 · script 本地资源 ✅ · localStorage ✅。 这就是渲染层必须用打包器（vite/webpack）的原因。

③ 启动优化清单（Q8，知识卡）

优化项做法
先建后显show: false + ready-to-show 再 show（本窗口已用）
窗口懒加载不启动建全部窗口，按需创建
主进程轻启动启动阶段避免重 IO / 同步大任务
渲染层瘦身bundle 瘦身、路由懒加载、首屏只渲染必要
后台节流隐藏窗口 backgroundThrottling、定时器清理
单实例requestSingleInstanceLock 防多开重复消耗
