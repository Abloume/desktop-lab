③ 签名与公证流程（Q7）

平台步骤
macOSDeveloper ID 证书签名 → hardened runtime + entitlements → notarytool 提交 Apple 公证 → 票据 staple 进包。四步缺一不可，否则 Gatekeeper 拦截
Windows代码签名证书（EV/OV）→ SignTool / builder 内置签名 → 降低 SmartScreen 拦截

自动更新前提：应用必须已签名（公证/签名流程不通过，无法发布更新）。
